# Política de Privacidade — Promac Mobile

Página estática da Política de Privacidade do aplicativo Promac Mobile.

## Publicação no GitHub Pages

O projeto é uma página estática para GitHub Pages. O arquivo principal é `index.html` e não há dependências ou etapa de compilação.

No GitHub, em **Settings → Pages**, selecione **Deploy from a branch**, escolha a branch `main` e a pasta `/(root)`. A página ficará disponível no endereço definido pelo GitHub Pages para o repositório.
